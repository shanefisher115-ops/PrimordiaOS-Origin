# Components

All UI components live in `src/app/components/`. They are written in TypeScript + React and styled exclusively with design token CSS variables and Tailwind v4 utility classes generated by `pnpm build:tokens`.

## Shared / Primitive Components

### `NeonProgressBar`

```tsx
import { NeonProgressBar } from "./components/NeonProgressBar";

<NeonProgressBar
  value={4280}        // current value
  max={5000}          // maximum value (default: 100)
  label="Level 7 → 8" // left label (optional)
  sublabel="86%"      // right label, colored in accent (optional)
  color="var(--semantic-color-accent-primary)" // fill color (optional)
/>
```

Tracks use `--component-progress-bar-track-color`, fill uses `--component-progress-bar-fill-color`, and radius uses `--component-progress-bar-radius`. All three are component tokens.

---

### `Skeleton` / `CardSkeleton` / `RowSkeleton`

Used in data-fetching components to prevent layout shifts during loading.

```tsx
import { Skeleton, CardSkeleton, RowSkeleton, ErrorState, EmptyState } from "./components/Skeleton";

// Single shimmer bar
<Skeleton height={14} width="40%" radius={8} />

// Card placeholder (multiple rows)
<CardSkeleton rows={3} />

// Row placeholder (icon + text + trailing value)
<RowSkeleton />

// Error with optional retry
<ErrorState message="Failed to load referrals." onRetry={load} />

// Empty state
<EmptyState message="No XP events today yet." />
```

---

### `.dt-btn-primary` / `.dt-btn-secondary`

CSS utility classes defined in `src/styles/base.css` and driven entirely by component tokens.

```tsx
// Primary — neon background, dark text, glow shadow, full radius
<button className="dt-btn-primary">
  Copy Link
</button>

// Secondary — transparent background, neon border + text, full radius
<button className="dt-btn-secondary">
  Send Reminder
</button>
```

Token values used:

| Class | Token |
|---|---|
| `dt-btn-primary` background | `--component-button-primary-background` |
| `dt-btn-primary` color | `--component-button-primary-text-color` |
| `dt-btn-primary` border-radius | `--component-button-primary-radius` |
| `dt-btn-primary` box-shadow | `--component-button-primary-shadow` |
| `dt-btn-secondary` border | `--component-button-secondary-border-color` |
| `dt-btn-secondary` color | `--component-button-secondary-text-color` |

### `Quests`

### `Badges`

**State:** fully local. Badge data is embedded.

**Badge props (internal):**

```ts
{
  id: string;
  name: string;
  desc: string;
  emoji: string;
  color: string;      // CSS color or var()
  colorRaw: string;   // hex, used for rgba() expressions
  rarity: "Common" | "Rare" | "Epic" | "Legendary";
  unlocked: boolean;
}
```

Locked badges apply `grayscale(1) opacity(0.25)` to the emoji and overlay a `<Lock>` icon.

## Data Fetching Pattern

All async components follow this pattern:

```tsx
const [data, setData]     = useState<T | null>(null);
const [loading, setLoading] = useState(true);
const [error, setError]   = useState<string | null>(null);

const load = useCallback(async () => {
  setLoading(true);
  setError(null);
  try {
    setData(await fetchSomething());
  } catch (err) {
    setError(err instanceof Error ? err.message : "Unknown error.");
  } finally {
    setLoading(false);
  }
}, []);

useEffect(() => { load(); }, [load]);
```

See `src/lib/api/mockData.ts` to toggle between mock and real Supabase data.

## Adding a New Component

1. Create `src/app/components/MyComponent.tsx`.
2. Use `var(--semantic-*)` or `var(--component-*)` for all colors, spacing, and radii.
3. For card surfaces: `bg-bg-card rounded-card p-layout shadow-card` + `border: "1px solid var(--semantic-color-border-subtle)"`.
4. For buttons: use `.dt-btn-primary` or `.dt-btn-secondary` CSS classes.
5. If the component fetches data, follow the `useState + useEffect + useCallback` pattern above and include `<Skeleton>`, `<ErrorState>`, and `<EmptyState>` for all three states.
6. Import and render it in `src/app/App.tsx`.

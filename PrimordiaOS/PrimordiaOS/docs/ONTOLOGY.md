# Primordia Ontology Specification

## Overview
The **Primordia Ontology** defines the structural classification, altitude, and sovereignty constraints governing all modules, files, and pipelines across PrimordiaOS.

## Classification Dimensions

### 1. Realms
- `local_realm`: Substrate root, local workstation, Termux, Node kernel.
- `cloud_realm`: Global edge mesh, Cloudflare AI Gateway, Cloud Shell, Workers.
- `simulation_realm`: Virtual physics space, Unreal Engine 5, Niagara VFX, WebSocket :17800.
- `economic_realm`: Syntropic value engine, MoneyPlugHub, syndicates, autonomous monetization loops.
- `identity_realm`: Immutable causal core, Osmium hash-chain ledger, sovereign identity.

### 2. Categories
- `kernel_core`: Master spine, state bus, event broker, orchestrator.
- `agent_guardian`: Tier 2 integrity enforcement (`AntigravGuardian`).
- `agent_domain`: Tier 3 realm operations (`RealmBuilder`, `LoopEngineer`, `InfraNavigator`, `LexiconScribe`).
- `agent_utility`: Tier 4 runners and reporting agents.
- `realm_adapter`: Bridges connecting the spine to physical substrates.
- `pipeline_edge`: Cloudflare & edge execution pipelines.
- `pipeline_simulation`: Unreal simulation event pipelines.
- `pipeline_monetization`: Autonomous monetization loops.
- `pipeline_multiagent`: Agent task dispatching and validation mesh.
- `simulation_engine`: In-engine physics and particle drivers.
- `identity_ledger`: Cryptographic append-only chain.
- `interface_hud`: Live cockpit and visualization displays.
- `vessel_container`: Host and platform container definitions.

### 3. Sovereignty Tiers
- **Tier 0**: Human Sovereign (`Shane`) — Absolute authority.
- **Tier 1**: Sovereignty Kernel — Supreme system rules.
- **Tier 2**: Guardian Agents — High auditing authority (`ANTIGRAV >= 70`).
- **Tier 3**: Domain Agents — Medium operational authority.
- **Tier 4**: Utility Agents — Low task authority.

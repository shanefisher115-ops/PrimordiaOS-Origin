\# PrimordiaOS Signal Processor



Input: Raw data from /live/sources/

Output: Normalized signals in /live/signals/stream.json



Rules:

\- If affiliate conversions increase → NEW\_AFFILIATE\_CONVERSION

\- If traffic jumps 50%+ → TRAFFIC\_SPIKE

\- If traffic drops 50%+ → TRAFFIC\_DROP

\- If bank balance changes → BALANCE\_CHANGED

\- If earnings = 0 by noon → ZERO\_EARNINGS\_TODAY

# Materials and Niagara systems

This guide covers every asset the visualizers drive, with build recipes for UE 5.4. **Parameter names are a contract.** The C++ sets exactly these names, so spelling and case must match. A missing parameter is silently ignored, which is why you can ship a simple material first and grow it later.

Until you build these assets, the plugin falls back to engine basic shapes with `BasicShapeMaterial` tinted through its `Color` parameter, so the pipeline is visible from the first run.

## Conventions shared by every material

- **`RetireAlpha`** (scalar, default 1) fades an entity out over its retire time. On opaque materials, use **Blend Mode = Masked** with `Opacity Mask = DitherTemporalAA(RetireAlpha)` for a fade that needs no translucency sorting. On translucent and additive materials, multiply it into emissive or opacity.
- **`Color`** (vector) is set on everything as a fallback tint. Your materials can ignore it.
- **The metaphysics collection.** Add a `CollectionParameter` node that references `MPC_PrimordiaMetaphysics` wherever a material should react to global state.

## 1. Emissive heartbeat material: `M_PrimordiaHeart`

**Applied to:** `AHeartActor::Core` (sphere). **Domain:** Surface · **Blend:** Masked · **Shading:** Default Lit.

| Param | Type | Driven by |
|---|---|---|
| Pulse | scalar 0–1 | lub-dub envelope, at frame rate |
| Intensity | scalar | `EmissiveBase + EmissivePulseGain × pulse × amplitude` (8 → ~48) |
| Coherence | scalar 0–1 | `heart_beat.coherence` |
| EssenceColor | vector | `heart_beat.essence` |
| RetireAlpha | scalar | fade |

**Graph**

1. `Rim = Fresnel(ExponentIn = Lerp(5, 1.5, Pulse), BaseReflectFraction = 0.04)`.
2. `Veins` = a `Noise` node (Simplex, 3D, Levels 4, Scale 0.02) on `AbsoluteWorldPosition + Time × (1 − Coherence) × 40`. Remap it to 0–1 and raise it to the power `Lerp(4, 1, Pulse)`. Incoherent hearts churn; coherent hearts are glassy.
3. `Emissive = EssenceColor × Intensity × (0.35 + 0.65 × Rim + 0.4 × Veins) × MPC.Luminosity`.
4. `BaseColor = EssenceColor × 0.05`, `Roughness = 0.2`, `Metallic = 0`.
5. **World Position Offset** = `VertexNormalWS × Pulse × 6 × Veins`, so the surface ripples on each beat.
6. `OpacityMask = DitherTemporalAA(RetireAlpha)`.

Pair this with a **Bloom** intensity of about 1.0 and **Lumen**, so the core lights the realm through `AHeartActor::Glow` (a point light pulsing 2 000 → 32 000 unitless).

## 2. Cosmic node and edge materials

### 2a. `M_PrimordiaCosmicNode`

**Applied to:** `ACosmicWebActor::Nodes` (instanced spheres; `NumCustomDataFloats = 4`). **Blend:** Masked · **Shading:** Unlit.

| Input | Source |
|---|---|
| PerInstanceCustomData[0] | resonance (0–1) |
| PerInstanceCustomData[1] | mass (1, 1.6, 3) |
| PerInstanceCustomData[2] | kind: 0 mote, 1 star, 2 nexus |
| RetireAlpha | fade |

**Graph**

1. `KindColor`: `Lerp(Lerp(MoteBlue (0.3,0.6,1), StarGold (1,0.85,0.5), saturate(Kind)), MPC.Essence, saturate(Kind − 1))`.
2. `Core = Fresnel(Exponent 2)` inverted (`1 − Fresnel`), so the centres are hot and the edges soft.
3. `Emissive = KindColor × (2 + 18 × Resonance) × (0.6 + 0.4 × Core) × MPC.Luminosity`.
4. Optional twinkle: `× (0.85 + 0.15 × sin(Time × (3 + Resonance × 9) + PerInstanceRandom × 6.28))`.
5. `OpacityMask = DitherTemporalAA(RetireAlpha)`.

### 2b. `M_PrimordiaCosmicEdge`

**Applied to:** `ACosmicWebActor::EdgeInstances`, one instanced static mesh holding every edge (one draw call for the whole web; `NumCustomDataFloats = 4`). Each edge is `EdgeSegments` (default 4) straight segments of the basic cylinder (its length runs along Z) laid along the edge's sag curve. **Blend:** Additive · **Shading:** Unlit · Two Sided · *Used with Instanced Static Meshes* checked (a cooked build won't render the material on an ISM without it).

| Input | Source |
|---|---|
| PerInstanceCustomData[0] | edge weight |
| PerInstanceCustomData[1] | mean endpoint resonance |
| PerInstanceCustomData[2] | segment start along the edge (0–1) |
| PerInstanceCustomData[3] | segment span (`1 / EdgeSegments`) |
| RetireAlpha | fade |

**Graph**

0. `EdgeV = PerInstanceCustomData[2] + TexCoord[0].y × PerInstanceCustomData[3]`. This is the position along the whole edge, so packets flow across segment joins.
1. `Flow = frac(EdgeV × 4 − Time × (0.5 + MPC.Resonance × 2))`. Energy packets travel the edge.
2. `Packet = smoothstep(0.0, 0.08, Flow) × (1 − smoothstep(0.08, 0.25, Flow))`.
3. `Emissive = (0.4, 0.7, 1.0) × Weight × (0.4 + 4 × Resonance × Packet) × RetireAlpha × MPC.Luminosity`.

## 3. Fate ribbon Niagara system: `NS_PrimordiaFateWeave`

**Driven by:** `AFateWeaveActor::PushToNiagara`. Threads are resampled to `PointsPerThread` points in C++ and written into **fixed slots**. A particle is a ribbon vertex, and a ribbon is a slot.

**Until you build it**, threads still render: `AFateWeaveActor::PushToTubes` draws each one as `PointsPerThread − 1` cylinder segments in a single instanced static mesh, so the whole loom is one draw call. Thickness follows the thread's `width`, and fading or severed threads thin out. The material is `M_PrimordiaThreadGlow`, which ships with the plugin and is generated by `Scripts/build_thread_material.py`. It is unlit and opaque: emissive = `PerInstanceCustomData[0..2]` (thread colour × fade) × `Intensity` (default 3), and bloom supplies the glow. Frayed threads flicker. Assigning a Niagara system switches the actor to ribbons.

### User parameters (System → User Exposed)

| Name | Type | Contents |
|---|---|---|
| ThreadPoints | **Array Position** (Niagara Position Array data interface) | `[Slot × PointsPerThread + k]`, local space, cm |
| ThreadColors | **Array Color** | `[Slot]`, linear HDR |
| ThreadParams | **Array Vector 4** | `[Slot]` = (tension, width cm, alpha, fate 0 bound / 1 frayed / 2 severed) |
| ThreadSlots | int | `MaxThreads` (default 16) |
| PointsPerThread | int | default 32 |
| LoomSpeed | float | `fate_weave.loom_speed` |
| WeaveDensity | float | `fate_weave.weave_density` |

### Emitter `Threads`

- **Sim target: CPU.** Ribbons with deterministic per-particle IDs are simplest on CPU, and at most 16 × 32 = 512 particles is trivial.
- **Local Space: ON.** Positions are relative to the actor.
- **Determinism:** ON.
- **Emitter Update:** *Emitter State* (Life Cycle: Self, Loop Behavior: Infinite). *Spawn Burst Instantaneous*: Spawn Count = `ThreadSlots × PointsPerThread`, Spawn Time 0.
- **Particle Spawn**
  - *Initialize Particle*: Lifetime Mode = **Infinite** (uncheck "Kill particles when lifetime has elapsed").
  - Scratch Pad module `InitThreadVertex`. Add a `Custom HLSL` node with inputs `ExecIndex` (Engine.ExecutionIndex) and `PointsPerThread`, and outputs `Slot` and `K`:

    ```hlsl
    Slot = ExecIndex / PointsPerThread;
    K    = ExecIndex - Slot * PointsPerThread;
    ```

    Write `Particles.ThreadSlot = Slot` (int), `Particles.RibbonID = Slot` (int), and `Particles.RibbonLinkOrder = (float)K`.
- **Particle Update**
  - Scratch Pad module `FollowThread`:
    1. `ThreadPoints.Get(Particles.ThreadSlot × PointsPerThread + K)`, written to `Particles.Position`. Store `K` as `Particles.ThreadPoint` at spawn so it is available here.
    2. `ThreadParams.Get(Particles.ThreadSlot)` gives `P`. Set `Particles.RibbonWidth = P.y × (P.w == 1 ? 0.6 + 0.4 × sin(Engine.Time × 13 + K) : 1)`, which jitters frayed threads.
    3. `ThreadColors.Get(Particles.ThreadSlot)` gives `C`. Set `Particles.Color = float4(C.rgb × (1 + 2 × (1 − P.x)), P.z)`. Slack threads glow hotter; alpha carries the sever fade.
    4. Frayed and severed threads: add `CurlNoise(Position × 0.01 + Time) × (1 − P.x) × 30` to the position.
  - *Dynamic Material Parameters* (index 0): `x = User.LoomSpeed`, `y = P.w` (fate), `z = User.WeaveDensity`.
- **Ribbon Renderer**
  - Material `M_PrimordiaFateRibbon`. Ribbon ID binding → `Particles.RibbonID`. Ribbon Link Order binding → `Particles.RibbonLinkOrder`. Width → `Particles.RibbonWidth`.
  - Facing: **Screen**. Shape: Plane. Tessellation: Custom, factor 4, curvature threshold 0.
  - UV0: Mode *Normalized Link Order* (U runs along the thread, V across it).

### `M_PrimordiaFateRibbon`

**Blend:** Additive · **Shading:** Unlit · Two Sided · *Used with Niagara Ribbons* checked.

1. `Core = pow(1 − abs(TexCoord.y × 2 − 1), 3)`: a bright filament with soft falloff.
2. `Shimmer = 0.7 + 0.3 × sin(TexCoord.x × 40 − Time × DynamicParameter.x × 6)`: light running along the loom.
3. `Fray = DynamicParameter.y ≥ 1 ? Noise(TexCoord × (30, 4) + Time) : 1`: a broken filament for frayed and severed threads.
4. `Emissive = ParticleColor.rgb × Core × Shimmer × Fray × ParticleColor.a × MPC.Luminosity`.

## 4. Dream nebula volumetric material: `M_PrimordiaDreamNebula`

**Applied to:** `ADreamNebulaActor::Volume` (a 100 uu cube scaled to `extent`). **Domain:** Surface · **Blend:** Translucent · **Shading:** Unlit · **Two Sided:** ON (so the nebula still renders when the camera is inside it) · *Disable Depth Test:* OFF · *Output Velocity:* OFF.

| Param | Type | Meaning |
|---|---|---|
| Density | scalar 0–1 | eased `dream_nebula.density` × RetireAlpha |
| Turbulence | scalar | fBm warp amount |
| NoiseScale | scalar | features per meter |
| Lucidity | scalar | sharpness: lucid dreams have crisp edges |
| DriftOffset | vector (cm) | accumulated `drift`, so the cloud flows |
| ExtentUnits | vector (cm) | full box size |
| ColorA / ColorB | vector | palette |
| RetireAlpha | scalar | fade |

**Graph:** one `Custom` node, output `Float4` (rgb = emissive, a = opacity).

Inputs:

- `Origin = CameraPositionWS − ObjectPositionWS`: the camera position relative to the box centre (do the subtraction in LWC, then *LWC To Float*).
- `RayDir = −CameraVectorWS`.
- `SceneDist = SceneDepth / dot(RayDir, CameraForwardWS)`. `CameraForwardWS` = `TransformVector(View→World, (0,0,1))`.
- `HalfExtent = ExtentUnits × 0.5`, plus `Density`, `NoiseScale`, `Turbulence`, `Lucidity`, `DriftOffset`, `ColorA`, `ColorB`, `Time`, and `Steps = 48`.

```hlsl
// Box-space raymarch (axis-aligned; nebulae are never rotated by the bridge).
struct N {
    float h(float3 p) { p = frac(p * 0.3183099 + 0.1); p *= 17.0; return frac(p.x * p.y * p.z * (p.x + p.y + p.z)); }
    float vn(float3 x) {
        float3 i = floor(x), f = frac(x); f = f * f * (3.0 - 2.0 * f);
        return lerp(lerp(lerp(h(i), h(i + float3(1,0,0)), f.x), lerp(h(i + float3(0,1,0)), h(i + float3(1,1,0)), f.x), f.y),
                    lerp(lerp(h(i + float3(0,0,1)), h(i + float3(1,0,1)), f.x), lerp(h(i + float3(0,1,1)), h(i + float3(1,1,1)), f.x), f.y), f.z);
    }
    float fbm(float3 p) { float a = 0.5, s = 0; for (int o = 0; o < 5; o++) { s += a * vn(p); p *= 2.03; a *= 0.5; } return s; }
};
N n;

float3 inv = 1.0 / RayDir;
float3 t0 = (-HalfExtent - Origin) * inv, t1 = (HalfExtent - Origin) * inv;
float3 tmn = min(t0, t1), tmx = max(t0, t1);
float tNear = max(max(max(tmn.x, tmn.y), tmn.z), 0.0);
float tFar  = min(min(min(tmx.x, tmx.y), tmx.z), SceneDist);
if (tFar <= tNear || Density <= 0.001) return float4(0, 0, 0, 0);

float stepLen = (tFar - tNear) / Steps;
float T = 1.0;           // transmittance
float3 L = 0;            // radiance
for (int i = 0; i < 64; i++) {
    if (i >= (int)Steps || T < 0.01) break;
    float3 p = Origin + RayDir * (tNear + (i + 0.5) * stepLen);
    float3 q = (p + DriftOffset) * NoiseScale * 0.01;                    // cm -> m frequency
    q += Turbulence * float3(n.fbm(q + 11.3), n.fbm(q + 7.1), n.fbm(q + 3.7));  // domain warp
    float d = n.fbm(q);
    float edge = 1.0 - smoothstep(0.6, 1.0, length(p / HalfExtent));     // fade at the box walls
    d = smoothstep(0.55 - 0.25 * Lucidity, 0.75, d) * edge * Density;    // lucidity sharpens
    float a = 1.0 - exp(-d * stepLen * 0.004);
    float3 c = lerp(ColorB, ColorA, saturate(d * 2.0));
    L += T * a * c;
    T *= 1.0 - a;
}
return float4(L * RetireAlpha, (1.0 - T) * RetireAlpha);
```

Connect `rgb` to **Emissive** and `a` to **Opacity**. Raise `Steps` for quality, or lower it to 24 on low-end hardware.

### `NS_PrimordiaDreamMotes` + `M_PrimordiaDreamMote` (optional, volumetric fog)

This makes nebulae light and occlude the world through **Volumetric Fog**. It requires an `ExponentialHeightFog` with *Volumetric Fog* enabled.

- **User params:** Density (float), Turbulence (float), Extent (vector, cm), ColorA, ColorB (linear color).
- **Emitter (GPU):** *Spawn Rate* = `200 × Density`. *Shape Location*: Box, size = `Extent`. Lifetime 4–8 s. *Curl Noise Force*: strength `Turbulence × 300`, frequency 0.002. Color = `Lerp(ColorA, ColorB, Random)`. Sprite size 300–900 cm.
- **Sprite Renderer** with `M_PrimordiaDreamMote`: **Material Domain = Volume**, Blend Additive. Set `Albedo = ParticleColor.rgb`, `Extinction = ParticleColor.a × 0.02 × SphereMask(ParticleRadius)`, and `Emissive = ParticleColor.rgb × 0.05`.

## 5. Shadow inversion shaders

### 5a. `M_PrimordiaShadowHull`: inverted-normal negative space

**Applied to:** `AShadowInversionActor::Hull`, a sphere with **reverse culling**: only the inner faces render, so it reads as a cavity cut into space. **Blend:** Masked · **Shading:** Unlit.

| Param | Meaning |
|---|---|
| Inversion | eased strength × RetireAlpha |
| Depth | how deep the cavity appears |
| Threshold | edge sharpness |
| Pulse | anti-beat (1 − heart pulse) |
| RetireAlpha | fade |

**Graph**

1. `N = normalize(VertexNormalWS)`. On interior faces, N points away from the viewer.
2. `Rim = pow(1 − abs(dot(N, CameraVectorWS)), Lerp(1.5, 6, Threshold))`.
3. `Abyss`: scroll the 3D noise *inward*. `Noise(AbsoluteWorldPosition × 0.01 + N × Time × (0.2 + Depth))` raised to `Lerp(1, 6, Depth)`.
4. `EdgeColor = 1 − MPC.Essence`: the negative of the realm's essence.
5. `Emissive = EdgeColor × Rim × Inversion × (2 + 6 × Pulse) + (0.02, 0, 0.04) × Abyss × Inversion`.
6. `OpacityMask = DitherTemporalAA(RetireAlpha)`.

### 5b. `PP_PrimordiaInversion`: post-process negative space

**Domain:** Post Process · **Blendable Location:** After Tonemapping · *Output Alpha:* OFF. It masks on the custom-depth **stencil** written by `StencilCore`. The actor sets `r.CustomDepth=3` at BeginPlay; for packaged builds also set *Project Settings → Rendering → Custom Depth-Stencil Pass = Enabled with Stencil*.

| Param | Meaning |
|---|---|
| Inversion | strength (0 disables the post-process volume entirely) |
| Threshold | luminance pivot |
| Pulse | edge flare |
| StencilValue | from settings (default 200) |

**Graph**

1. `Scene = SceneTexture:PostProcessInput0.rgb`, `Stencil = SceneTexture:CustomStencil.r`.
2. `Mask = 1 − saturate(abs(Stencil − StencilValue) − 0.5)`. This is 1 inside the shadow core.
3. Outline: sample `CustomStencil` at ±2 px (with `ViewSize` / `SceneTexelSize`). Set `Edge = Mask × (1 − min of the 4 neighbour masks)`.
4. `Luma = dot(Scene, (0.2126, 0.7152, 0.0722))`. Set `Negative = lerp(1 − Scene, (1 − Luma).xxx, smoothstep(Threshold − 0.2, Threshold + 0.2, Luma))`, so bright areas desaturate into negative.
5. `Out = lerp(Scene, Negative, Mask × Inversion) + Edge × (1 − MPC.Essence) × Pulse × 3`.

## 6. Volumetric sigils: `M_PrimordiaSigilVolume`

Glyphs are written in light, not painted on a card. Each glyph is raymarched inside a cube, and every step adds the glow of the nearest luminous structure. Strokes therefore have soft, light-filled depth and read from any side.

**Ships with the plugin** and is the default `GlyphMaterial`. With *Settings → Assets → Soul → bVolumetricGlyphs* on (the default), `ASoulGlyphActor` swaps its plane for a 100 uu cube scaled to the glyph's diameter and stops billboarding. **Blend:** AlphaComposite (premultiplied) · **Shading:** Unlit · **Two Sided:** ON. The front faces shade from outside the cube and the back faces from inside, never both.

The material is a thin wrapper. It computes the view ray in the cube's local space and calls `PrimordiaSigilVolume()` in `Shaders/Private/PrimordiaSigil.ush`, where all of the design lives. The `PrimordiaOSRealmBridgeShaders` module maps that folder to `/Plugin/PrimordiaOSRealmBridge`. To rebuild the asset after changing the graph, run `Scripts/build_sigil_material.py` (see its docstring). Shader edits only need the material to recompile.

### Meaning: what each glyph shows

| Kind | Archetype | Reads as |
|---|---|---|
| soul (0) | **Heart of unification.** A kaleidoscopic inversion fractal folded `Symmetry` ways. Diffuse and restless at low `Unity`, a crisp crystal at high `Unity`. A core brightens as fragments merge, and the realm's name is written around it as a crown. | the realm's self |
| sigil (1) | **Written intent.** The intent's monogram drawn upright in light, with a circle where the writing begins and a bar where it ends. A pulse of light runs along it in writing order. A fainter mirrored echo sits behind it (stronger with `Complexity`), and a seal ring carries `Symmetry` notches. | a statement made real |
| ward (2) | **Armillary of protection.** 2–6 counter-rotating rings (from `Symmetry`), each tilted on a golden-angle axis. The intent's letters ride the rings as beads, the monogram is held at the centre, and a faint shield of hexagonal cells surrounds it. | something kept safe |
| gate (3) | **Threshold.** An upright portal ring with `Symmetry` pillars of light. Its aperture is a spiral vortex that falls away into depth, and the monogram sits above it as a keystone. | a way through |

**Inscription.** `PrimordiaSigil::Inscribe` (C++) turns the glyph's PRS-1 `intent` into its monogram, the way sigils have long been made from a statement of desire:

1. Keep A–Z.
2. Strike the vowels (except a leading one) and every repeated letter: `GUARD THE DREAM OF LUMENNE` → `GRDTHMFLN`.
3. Place each letter on a three-ring wheel: vowels inside, B–L in the middle, M–Z outside, read clockwise from 12 o'clock. Join them in order, up to 12 points.

The same intent always yields the same glyph. Without an intent, the glyph is inscribed from its id.

**Metaphysics** (pushed per glyph by `ApplyMetaphysics`):
- `Coherence` sharpens light into lines.
- `Entropy` makes the structure shiver.
- `Resonance` speeds the ink and the breathing.
- `Inversion` turns light to its complement and lets the aura swallow what lies behind.
- `Luminosity` is overall gain.
- `Lucidity` deepens the gate's vortex.
- `Essence` tints cores and auras.

| Param | Meaning |
|---|---|
| GlyphKind, Symmetry, Complexity, Unity, Spin, Hue, RetireAlpha | as in the plane material below |
| SigilStrokes | number of monogram points (0–12) |
| SigilPoints0..5 | monogram points, two per vector: (x0, y0, x1, y1) in [-1, 1] |
| SigilSeed | [0, 1) hash of the inscribed letters: the inscription's own phase |
| Entropy, Coherence, Inversion, Luminosity, Resonance, Lucidity, Essence | realm metaphysics, eased |
| Steps | raymarch step budget (default 48, up to 128). Steps adapt to distance: long strides through empty space, fine ones near light, so integrated GPUs stay interactive |

### Plane mode: `M_PrimordiaSoulGlyph` (optional)

Turn `bVolumetricGlyphs` off to draw glyphs on a billboarded plane with your own flat material instead, for example the fractal below.

**Applied to:** `ASoulGlyphActor::GlyphPlane` (a plane billboarded to the viewer). **Blend:** Additive · **Shading:** Unlit · **Two Sided:** ON.

| Param | Meaning |
|---|---|
| Symmetry | n-fold mirror symmetry (int as float) |
| Complexity | fractal iterations (2–8) |
| Hue | base hue |
| Unity | soul unification: sharper, brighter, more ordered |
| Spin | accumulated rotation (radians), so speed changes never jump |
| GlyphKind | 0 soul, 1 sigil, 2 ward, 3 gate |
| RetireAlpha | fade |

**Graph:** a `Custom` node returning `Float3`. Inputs: `UV` (TexCoord0), Symmetry, Complexity, Hue, Unity, Spin, GlyphKind, `Time`.

```hlsl
float2 p = (UV - 0.5) * 2.0;
float r = length(p);
float seg = 6.2831853 / max(Symmetry, 1.0);
float a = atan2(p.y, p.x) + Spin;
a = abs(fmod(a + 64.0 * seg, seg) - 0.5 * seg);           // fold into one mirrored wedge
p = float2(cos(a), sin(a)) * r;

// Kali-set inversion fractal: each fold adds filigree; Unity tightens it.
int iters = 2 + (int)(Complexity * 6.0);
float glow = 0.0, w = 1.0;
float c = 0.62 + 0.16 * Unity + 0.03 * sin(Time * 0.3);
for (int i = 0; i < 8; i++) {
    if (i >= iters) break;
    p = abs(p) / max(dot(p, p), 1e-3) - c;
    glow += w * exp(-abs(length(p) - 1.0) * (4.0 + 12.0 * Unity));
    w *= 0.72;
}

// Containment rings; wards get a third ring, gates get a gap.
float ring = exp(-abs(r - 0.86) * 60.0) + 0.6 * exp(-abs(r - 0.94) * 120.0);
if (GlyphKind > 1.5 && GlyphKind < 2.5) ring += 0.6 * exp(-abs(r - 0.7) * 90.0);
if (GlyphKind > 2.5) ring *= step(0.15, abs(sin(atan2(UV.y - 0.5, UV.x - 0.5) * 0.5)));

float mask = 1.0 - smoothstep(0.96, 1.0, r);
float I = (glow * 0.35 + ring) * mask;

// Hue -> RGB (HSV with S = 0.65, V = 1), sweeping slightly outward.
float h = frac(Hue + r * 0.08);
float3 rgb = saturate(abs(frac(h + float3(0, 2.0/3.0, 1.0/3.0)) * 6.0 - 3.0) - 1.0);
rgb = lerp(1.0.xxx, rgb, 0.65);
return rgb * I;
```

`Emissive = Custom × (2 + 20 × Unity) × MPC.Luminosity × RetireAlpha`.

## 7. Layer materials and art: `M_PrimordiaLayer`

Each layer is a base mesh plus up to three instanced **tiers** (PRS-1 §4.3): *fixed* (always shown), *hero* (few, large) and *detail* (many, small). Every tier is one component per mesh variant, so each tier costs **one draw call per variant per pass**, whatever its instance count.

### 7a. Asset slots

- It has no WPO: on shadow-casting instances, WPO makes virtual shadow maps re-render every frame.
- The instances differ in `EmissiveGain`, `Metallic` and `RoughnessBase`, and in four surface terms (the `KINDS` table in the script):
  - `MacroVariation`: two octaves of world-space noise (24 m and 4.8 m) on albedo, roughness and the secondary→primary mix. It breaks up the big flat discs.
  - `SideTint`: faces that don't point up (terrace cliffs) lean to `SecondaryColor` and darken, so each step reads as a ledge.
  - `HeightShade`: an instance is darker at its foot than its top, from the height in instance space (engine shapes span −50..50 cm). It stands in for the occlusion that the iGPU settings (no Lumen, no distance fields) don't give.
  - `TipGlow`: the top tenth of an instance glows in `(Color + Essence) / 2 × Luminosity`, so spire crowns light up.

**Mesh authoring rules** (the generator scales your mesh exactly like the engine shape it replaces):
- Fit the mesh in a **100 cm box with the pivot at its centre**. Length runs along +Z for terraces, sea stacks, spires, skirts and struts, and along +X for keystones and shards (the orbit tangent). Monolith slabs are thin in X and broad in Y; local +X faces the circle's centre.
- Enable **Used with Instanced Static Meshes** on every material that a tier uses.
- **Integrated GPU (Ryzen 3 4300U / Radeon Vega).** Use **non-Nanite** meshes with **3 LODs** (screen size about 0.5 / 0.15 / 0.04). Keep detail meshes at or under 200 triangles at LOD0, and hero meshes at or under 2k. Detail tiers use HISM by default (`bHierarchicalDetailTiers`), which only pays off when the meshes have LODs.
- A mesh with several material slots gets the tier material in **all** of them. Use one slot per mesh to keep one draw per variant.

**Cost knobs** (*Settings → Realm Detail*): `bEnableDetailTiers` (off = no detail components; turning it back on takes a Regenerate), `DetailDensityScale` (0–1, a prefix, applied on the next density change), `bHierarchicalDetailTiers`. `UPrimordiaRealmGenerator::MaxScatterPerLayer` (default 2000) caps every tier.

For measuring (the user's "measure, change one thing, measure again" loop), a typical genesis realm (ground + sky + two extras) draws about 10 tier components per pass. Before tiers it was about 5. Shadows only add passes for the shadowed tiers above. Compare `stat rhi` with `bEnableDetailTiers` on and off.

**Metaphysics belong here, on the GPU.** Placement never reacts to metaphysics (PRS-1 §4.3), so every visible reaction to them is a material effect: MPC or MID scalars combined with the custom data above. That costs nothing on the CPU.

### 7c. Suggested looks per kind

- **ground**
  - Terraces: `BaseColor = lerp(SecondaryColor, Color, Noise(WorldPos × 0.001))`, `Roughness = 0.6 + 0.4 × roughness`, darken toward the lower steps with `[3]`.
  - Cracks: emissive `Essence × Inversion × 0.2` along a crack mask, stronger on circle stones (`[3] ≥ 0.6`).
  - **Entropy:** WPO jitters only lone stones (`[3] = 0`) by `Entropy × 3 cm × sin(Time × 7 + [0] × 40)`, so circles stay calm while the realm is stormy.
  - **Coherence:** brightens a rune band on circle stones.
- **ocean**
  - Surface: WPO waves `= sin(dot(WorldPos.xy, dir) × 0.002 + Time × wave_speed) × wave_height`, low roughness, Fresnel tinted by `Color`.
  - Sea stacks: a wet band where `LocalZ` is near the waterline. `[3]` gives the emerged fraction.
  - Motes: unlit; they bob with `[0]`.
- **sky**
  - Stars: unlit, `Color × (5 + 20 × Luminosity) × (0.2 + [1])`. Twinkle `= 1 + 0.5 × Entropy × sin(Time × (3 + 9 × [0]))`. Band stars (`[3]`) are tinted toward `Essence × Lucidity`.
  - Beacons: emissive halos that pulse with `Resonance`.
- **ring**
  - Lit and metallic, with emissive edges `= Color × Fresnel × (1 + 4 × Coherence)`.
  - Orbit WPO: rotate each shard about the layer's Z axis by `Time × 0.02 × (1 + [2])`. Use the instance origin, not the vertex, so shards stay rigid.
- **lattice**
  - Nodes glow `Color × (1 + 4 × Coherence) × [1]`.
  - Struts carry a flow pulse along their axis, `frac(Time × Resonance + [0])`.
  - **Entropy** fades struts out (masked dither by `Entropy > [0]`), so a stormy lattice breaks apart with no CPU cost.
- **spire_field**
  - Lit and metallic. Crowns (`[3]` near 1) get an emissive tip that grows with `Luminosity`.
  - Skirts: rougher and darker.
  - **Inversion** darkens toward `1 − Essence` from the tip down.
- **void**
  - Shell: unlit, `Emissive = SecondaryColor × 0.02`, plus a faint `1 − Essence` rim. The mesh uses reverse culling, so this paints the inside of the hollow.
  - Core: an event horizon. Black, with a Fresnel ring `Essence × (2 + 8 × Inversion)`.
  - Debris: lit by the core. The inner disc (`[2]` near 0) is hottest; it orbits with WPO by phase `[3]`.

### Real architecture: the free Gothic Revival Church

The model is *Gothic Revival Church - White - 3D Model* by **EFADKZ** on Fab, licensed **CC BY 4.0**. Credit the author wherever you share renders. It isn't in this repo. To set it up:

The "Lite" model's towers end in open belfries, so the script caps each with a spire and four corner pinnacles, placed from the tower tops measured off the mesh (`CHURCH_TOWERS`).

**Surface maps.** `M_CathedralStone` takes `StoneNormal` (flat by default) and `StoneRoughness` (linear white by default; dry roughness = map × `RoughnessDry`), so untextured surfaces keep the procedural look.

**Window glow.** `M_CathedralStone` can light windows on any textured building, controlled by `WindowEmissive` (0, so off, by default). It glows where the albedo is darker than `WindowThreshold` and the surface is close to vertical (`WindowVertical`), which picks out glass and skips dark roofs. The glow is cut into leaded diamond panes (`LeadSize`, in cm), and each 12 m column of the building is cyan (`WindowColorA`) or, for a `WindowColorMix` share, magenta (`WindowColorB`). With the church textured, every one of its windows lights up, and the separate window planes are skipped.

### Notes on common look-guide advice

- **Emissive ≈ 50** assumes physical camera exposure. The scene uses manual exposure with physical exposure off, and the whole frame is scaled by `2^EXPOSURE_COMPENSATION` (+1). That puts window emissive near 0.35 and ring intensity near 4. If you turn physical camera exposure on, multiply emissive by about 40.
- **Volumetric fog albedo:** keep it bright (about 0.85). A dark albedo scatters less light and kills the god rays. Make the fog darker with fog density or extinction instead.
- **Rect lights in the fog** need a non-zero *Volumetric Scattering Intensity*, otherwise the windows won't glow into the haze.
- **Convolution bloom** costs a lot and needs a kernel texture. Set `CONVOLUTION_BLOOM = True` in the script for cinematics. The default (standard bloom, large size) gets close for real time.
- **Hardware ray-traced Lumen** is a project setting, so the script doesn't change it: *Project Settings → Rendering → Support Hardware Ray Tracing*, then *Lumen → Use Hardware Ray Tracing when available* (DX12, needs a restart).
- **Nanite doesn't render translucent or additive materials.** The stone can be Nanite, but the rings and any see-through glass must stay on non-Nanite meshes or in Niagara.

### Upgrading the rings to Niagara ribbons

Python can't author Niagara emitter stacks, so the shipped rings are shader planes. For particle rings, build `NS_CathedralRings` by hand and drop it at each ring centre:

- **Spawn:** *Spawn Burst Instantaneous* (about 400). *Shape Location* = Torus (large radius = ring radius, small radius ≈ 0.5 m), or a Ring/Disc shape.
- **Ribbon order:** a ribbon joins particles in spawn order, so random torus points make a tangle. Set *Ribbon ID* per ring (e.g. `ExecutionIndex % RingCount`) and *Ribbon Link Order* = the angle around the ring (`atan2(Position.y, Position.x)`). Close the loop by spawning one extra particle at angle 2π.
- **Motion:** *Rotate Around Point* (or orbit velocity) for the swirl, plus a small *Curl Noise Force* (strength about 20, frequency about 0.02) for the vibration.
- **Renderer:** *Ribbon Renderer*, UV0 tiled along the ribbon. Use an additive unlit material with `Used with Niagara Ribbons` enabled: emissive = colour × (Fresnel + core) × a noise texture panned along U for the flowing light.
